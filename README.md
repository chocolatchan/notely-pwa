# Notely - Offline Smart Note & Todo PWA

This project is a Progressive Web App (PWA) built with React and Vite.

## Project Structure
- `src/components`: UI components.
- `src/lib/db.ts`: IndexedDB wrapper for offline storage.
- `src/lib/push.ts`: Push Notification logic.
- `src/pages`: Main application pages.
- `src/service-worker.ts`: Custom service worker for PWA features.

## Getting Started (Docker)
1. Ensure Docker is installed.
2. Run `docker-compose up` from the parent directory (`mid_term/`).
3. Open `http://localhost:5173` in your browser.
